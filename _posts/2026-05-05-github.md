## Overview

<b>Problem Statement:</b> GitHub provides access to only the past 14 days of repository traffic data. Existing solutions are not simple and are not designed for the specific output I want.

<b>Solution:</b> This tracker stores daily GitHub traffic data and calculates cumulative counts for total and unique repository views and clones.

<b>Note:</b> This tracker is designed for a single repository. A separate tracker should be created for each repository.

---

## What this tracker records

The output CSV includes:

- Daily total views
- Daily unique views
- Daily total clones
- Daily unique clones
- Cumulative total views
- Cumulative unique views
- Cumulative total clones
- Cumulative unique clones

<b>Important:</b> GitHub provides only a rolling 14-day traffic window. Therefore, cumulative values must be calculated from the saved daily records, not from GitHub’s 14-day totals.

## Step 1: Create a GitHub Personal Access Token (PAT)

Go to:

`Settings > Developer Settings > Tokens (classic)`

Create a token with the repo scope.

Required permissions:

`Metadata and Administration - Read only`

Save the token. It will be used later as:

`GH_TOKEN`

## Step 2: Create a Google Service Account and JSON key

Go to the Google Cloud Console.

Create a new project:

1. Click the navigation menu on the top-left corner.
2. Select `APIs & Services > Enable APIs & Services`.
3. Create a project.
4. Name your project.
5. Select the organization. I selected `No organization`.

Enable the Google Drive API:

1. Use the search bar at the top.
2. Search for `Google Drive API`.
3. Click on it.
4. Click `Enable`.

Create a service account:

1. Click the navigation menu again.
2. Select `IAM & Admin > Service Accounts`.
3. Click `Create Service Account`.
4. Enter a `Service Account Name`.
5. Click `Create and continue`.
6. Under permissions, select `Basic > Editor`.
7. Click `Done`.

Create the JSON key:

1. Click the email hyperlink for the service account you just created.
2. Go to the `Keys` tab.
3. Click `Add key`.
4. Select `Create new key`.
5. Select key type: `JSON`.
6. Download the JSON file.

This JSON file will be used later as:

`GDRIVE_JSON`

## Step 3: Create the Google Drive CSV file

Open Google Drive in your browser.

Create or select the folder where you want the CSV file to be saved.

Open the JSON file you downloaded and copy the `client_email` value.

It should look like this:

`name@project-id.iam.gserviceaccount.com`

Share the Google Drive folder with that email address and give it `Editor` permission.

Create a CSV file, for example:

`traffic states.csv`

Open the CSV file and copy the file ID from the URL.

Example URL:

`https://docs.google.com/spreadsheets/d/1sdsN3bo-kX8dsdsrawMI/edit?gid=22392112#gid=22392112`

The file ID is this part:

`1sdsN3bo-kX8dsdsrawMI`

This value will be used in the `FILE_ID` line of the `get_traffic.py` script.

## Step 4: Add the Python script to your GitHub repository

Go to the GitHub repository that you want to track.

Create a file named:

`get_traffic.py`

Create this file in the main directory of the repository, not inside a folder.

Before running the script, edit these two lines:

### Repository name

Change the `REPO` line to your repository path.

Example:

`REPO = "JohnDoe/WeatherApp"`

### Google Drive file ID

Change the `FILE_ID` line to the ID of your Google Drive CSV file.

Example:

`FILE_ID = "1sdsN3bo-kX8dsdsrawMI"`

Paste the following code into `get_traffic.py`:

<div style="max-height: 220px; overflow-y: auto;">
{% highlight python %}

import os
import requests
import pandas as pd
import io
from datetime import datetime, timezone
from google.oauth2 import service_account
from googleapiclient.discovery import build
from googleapiclient.http import MediaFileUpload, MediaIoBaseDownload

# Configuration
REPO = "" #CHANGE ME: e.g., "oskuddar/trnL_DB"
GITHUB_TOKEN = os.getenv("GH_TOKEN")
FILE_ID = "" #CHANGE ME: e.g., "1sdsN3bo-kX8dsdsrawMI"

OUTPUT_COLUMNS = [
    "date",
    "daily_total_views",
    "daily_unique_views",
    "daily_total_clones",
    "daily_unique_clones",
    "cumulative_total_views",
    "cumulative_unique_views",
    "cumulative_total_clones",
    "cumulative_unique_clones"
]

def get_github_traffic():
    headers = {"Authorization": f"token {GITHUB_TOKEN}"}
    today_date = datetime.now(timezone.utc).strftime("%Y-%m-%d")

    # Fetch Views
    views_res = requests.get(
        f"https://api.github.com/repos/{REPO}/traffic/views",
        headers=headers,
        params={"per": "day"}
    ).json()

    # Fetch Clones
    clones_res = requests.get(
        f"https://api.github.com/repos/{REPO}/traffic/clones",
        headers=headers,
        params={"per": "day"}
    ).json()

    today_views = {"count": 0, "uniques": 0}
    today_clones = {"count": 0, "uniques": 0}

    for view_entry in views_res.get("views", []):
        if view_entry.get("timestamp", "")[:10] == today_date:
            today_views = view_entry
            break

    for clone_entry in clones_res.get("clones", []):
        if clone_entry.get("timestamp", "")[:10] == today_date:
            today_clones = clone_entry
            break

    return {
        "date": today_date,
        "daily_total_views": today_views.get("count", 0),
        "daily_unique_views": today_views.get("uniques", 0),
        "daily_total_clones": today_clones.get("count", 0),
        "daily_unique_clones": today_clones.get("uniques", 0)
    }

def update_drive_file(current_stats):
    with open("credentials.json", "w") as f:
        f.write(os.getenv("GDRIVE_JSON"))

    creds = service_account.Credentials.from_service_account_file("credentials.json")
    service = build("drive", "v3", credentials=creds)

    # 1. Download existing data
    request = service.files().export_media(fileId=FILE_ID, mimeType="text/csv")
    fh = io.BytesIO()
    downloader = MediaIoBaseDownload(fh, request)
    done = False

    while done is False:
        status, done = downloader.next_chunk()

    fh.seek(0)

    try:
        df = pd.read_csv(fh)
    except Exception:
        df = pd.DataFrame(columns=OUTPUT_COLUMNS)

    if df.empty:
        df = pd.DataFrame(columns=OUTPUT_COLUMNS)

    # 2. Keep the required columns
    for column_name in OUTPUT_COLUMNS:
        if column_name not in df.columns:
            df[column_name] = 0

    df = df[OUTPUT_COLUMNS]

    # 3. Clean existing data
    df["date"] = pd.to_datetime(df["date"], errors="coerce").dt.strftime("%Y-%m-%d")
    df = df.dropna(subset=["date"])

    numeric_columns = [column_name for column_name in OUTPUT_COLUMNS if column_name != "date"]

    df[numeric_columns] = df[numeric_columns].apply(
        pd.to_numeric,
        errors="coerce"
    ).fillna(0).astype(int)

    # 4. Add today's row only
    new_row = pd.DataFrame([current_stats])

    for column_name in OUTPUT_COLUMNS:
        if column_name not in new_row.columns:
            new_row[column_name] = 0

    new_row = new_row[OUTPUT_COLUMNS]
    new_row["date"] = pd.to_datetime(new_row["date"], errors="coerce").dt.strftime("%Y-%m-%d")
    new_row[numeric_columns] = new_row[numeric_columns].apply(
        pd.to_numeric,
        errors="coerce"
    ).fillna(0).astype(int)

    df = pd.concat([df, new_row], ignore_index=True)

    # 5. Prevent duplicate row if workflow runs more than once today
    df = df.sort_values("date")
    df = df.drop_duplicates(subset=["date"], keep="last")

    # 6. Recalculate cumulative columns from saved daily rows
    df["cumulative_total_views"] = df["daily_total_views"].cumsum()
    df["cumulative_unique_views"] = df["daily_unique_views"].cumsum()
    df["cumulative_total_clones"] = df["daily_total_clones"].cumsum()
    df["cumulative_unique_clones"] = df["daily_unique_clones"].cumsum()

    df = df[OUTPUT_COLUMNS]

    # 7. Upload updated CSV
    local_csv = "temp_traffic.csv"
    df.to_csv(local_csv, index=False)

    media = MediaFileUpload(local_csv, mimetype="text/csv")
    service.files().update(fileId=FILE_ID, media_body=media).execute()

    print(
        f"Update complete. Date: {current_stats['date']}. "
        f"Daily views: {current_stats['daily_total_views']}. "
        f"Daily clones: {current_stats['daily_total_clones']}."
    )

if __name__ == "__main__":
    data = get_github_traffic()
    update_drive_file(data)

## Step 5: Create the GitHub Actions workflow

Create this folder in your repository:

`.github/workflows`

Inside that folder, create this file:

`daily_traffic.yml`

Paste the following code into `daily_traffic.yml`:

<div style="max-height: 220px; overflow-y: auto;">
{% highlight yml %}

name: Daily Traffic Sync
on:
  schedule:
    - cron: '0 0 * * *' # Runs daily at midnight UTC
  workflow_dispatch:   # Allows you to click "Run workflow" manually

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          pip install requests pandas google-api-python-client google-auth-httplib2 google-auth-oauthlib

      - name: Run script
        env:
          GH_TOKEN: ${{ secrets.GH_TOKEN }}
          GDRIVE_JSON: ${{ secrets.GDRIVE_JSON }}
        run: python get_traffic.py
        
{% endhighlight %}

## Step 6: Configure GitHub repository secrets

In your GitHub repository, go to:

`Settings > Secrets and variables > Actions`

Click:

`New repository secret`

Create the following two secrets.

### Secret 1

Name:

`GH_TOKEN`

Value:

Paste your GitHub Personal Access Token.

### Secret 2

Name:

`GDRIVE_JSON`

Value:

Open your Google Service Account JSON file, copy the entire content, and paste it here.

## Step 7: Test the workflow

Go to the `Actions` tab in your GitHub repository.

Click:

`Daily Traffic Sync`

Look for this message:

`This workflow has a workflow_dispatch event trigger.`

Click:

`Run workflow > Run workflow`

After the workflow finishes, open your Google Drive CSV file and check whether a new row was written.
